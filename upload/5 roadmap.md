# ДОРОЖНАЯ КАРТА (ROADMAP) – NARRATIVECORE

## Версия 1.0 – MVP и план развития до версии 3.0

Все сроки указаны в человеко-неделях при команде из 3 разработчиков (1 бэкенд, 1 фронтенд, 1 DevOps/AI). Возможны сдвиги.

---

## 1. МVP (ВЕРСИЯ 1.0) – 12 НЕДЕЛЬ (3 МЕСЯЦА)

### Недели 1–2: Подготовка базы и аутентификация

| Задача | Исполнитель | Время |
|--------|-------------|-------|
| Настройка монорепозитория (Turborepo, pnpm workspace) | DevOps | 2 дня |
| Docker Compose (PostgreSQL, Redis, MinIO, Nginx) | DevOps | 1 день |

| JWT аутентификация (регистрация, логин, /me) | Backend | 2 дня |
| Базовый React (Vite + FSD), роутинг, Zustand | Frontend | 3 дня |
| Страница входа/регистрации | Frontend | 2 дня |

## 5. УПРАВЛЕНИЕ РИСКАМИ ПО СРОКАМ

| Риск | Влияние | Митигация |
|------|---------|------------|
| Задержки с интеграцией OpenAI API (квоты, биллинг) | MVP – AI-генерация может выпасть | Сделать заглушку (локальные шаблоны) для тестирования, API подключить в последний момент |
| Сложность с pgvector и эмбедингами | Версия 2.0 может сдвинуться | Использовать готовые решения (pgvector) и выделить отдельный спринт на индексацию |
| Нехватка фронтенд-ресурсов (FSD требует времени на привыкание) | MVP | Нанять второго фронтендера или увеличить сроки на 2 недели |
| Платежный шлюз (Stripe) – юридические вопросы | MVP | Использовать ЮKassa для РФ и Stripe для международных; начать с ручной выписки инвойсов на бета-тесте |
