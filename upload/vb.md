# Экосистема Vibe — Краткое описание

## Концепция

**Vibe** — это интегрированная платформа творческих инструментов с искусственным интеллектом, которая сопровождает пользователя на всём пути: от мимолётной мысли до готового цифрового продукта (текста, приложения, музыки, видео). Единый профиль, единый биллинг, бесшовный обмен данными между сервисами.

## Состав экосистемы (MVP + дорожная карта)

| Сервис | Назначение | Статус |
|--------|------------|--------|
| **VibeMind** | Дневник мыслей с асинхронным ИИ-анализом (текст/голос → рефлексия через час) | ✅ Готов (PRD) |
| **VibeStudio** | Среда разработки приложений на естественном языке (идея → SPEC → код → деплой) | 🚧 В разработке |
| **NarrativeCore** | Инструмент для писателей/сценаристов: управление миром, персонажами, редактор текста, проверка канона | 📐 Спроектирован |
| **VibeWriter** | AI-соавтор для текстов (статьи, посты, сценарии, письма) с экспортом на платформы | 📋 Планируется |
| **VibeCompositor** | Музыкальный редактор с AI-генерацией, интеграция с NarrativeCore (лейтмотивы персонажей) | 📋 Планируется |
| **VibeMovieMaker** | Видеоредактор с AI-монтажом, интеграция со сценарием (Writer) и музыкой (Compositor) | 📋 Планируется |
| **VibeCore** | Единое ядро: авторизация, биллинг, дашборд, админ-панель, API Gateway, микрофронтенды | 🏗️ В проектировании |

## Сквозные возможности экосистемы

1. **Единый вход (SSO)** — одна учётная запись для всех сервисов.
2. **Единый биллинг** — общие подписки (Free/Pro/Team), покупка дополнительных AI-кредитов.
3. **Общий профиль и настройки** — единый дашборд, лента активности, уведомления.
4. **Контекстный роуминг** — данные перетекают между сервисами:
   - Мысль из **VibeMind** → бриф для **VibeStudio** или черновик для **VibeWriter**.
   - Персонаж из **NarrativeCore** → тема в **VibeCompositor** → визуал в **VibeMovieMaker**.
   - Сценарий из **VibeWriter** → автоматическая раскадровка и монтаж в **VibeMovieMaker**.
5. **Единый API Gateway** и микрофронтенды (Module Federation) — все сервисы работают как одно SPA-приложение.

## Пользовательские сценарии (примеры)

### Сценарий 1: Писатель / Сценарист
1. Записывает идею в **VibeMind** → через час получает структурированный разбор.
2. Переносит идею в **NarrativeCore** — создаёт мир, персонажей, локации, пишет главы.
3. Использует **AI-генерацию** в NarrativeCore для доработки сюжета и иллюстраций.
4. Экспортирует сценарий в **VibeWriter** для финальной стилистической правки.
5. Отправляет сценарий в **VibeMovieMaker** → получает черновой видеомонтаж с автоматической раскадровкой.

### Сценарий 2: Блогер / Видеомейкер
1. Пишет пост или сценарий в **VibeWriter** (или импортирует из VibeMind).
2. В **VibeCompositor** создаёт фоновую музыку (или AI генерирует по настроению текста).
3. В **VibeMovieMaker** собирает видео: импортирует сценарий, добавляет сгенерированную музыку, накладывает субтитры.
4. Экспортирует готовый ролик и публикует напрямую в соцсети.

### Сценарий 3: Предприниматель / Стартапер
1. Фиксирует бизнес-идею в **VibeMind** → получает анализ.
2. Открывает **VibeStudio** → заполняет бриф из VibeMind, общается с AI-аналитиком.
3. Утверждает SPEC.md → запускает автоматическую кодогенерацию.
4. Получает работающее приложение, развёрнутое по ссылке.
5. Создаёт презентационное видео в **VibeMovieMaker** с использованием готового интерфейса.
