# PocketStudio — Roadmap

> Карманная творческая студия: **Идея → Создание → Монетизация**.
> Chat-first кокпит + модули студии. Один оркестратор на весь творческий конвейер.
> Название «PocketStudio» — рабочее (проверка занятости — отдельная задача).

## Принцип «редакторов» (утверждён пользователем)

Мы **не конкурируем** с Adobe / Figma / Image-Line / MAGIX. Каждый редактор платформы —
**минимально базовый набор ручных правок для тех, кто умеет** работать в профессиональных
инструментах. **Основной инструмент платформы остаётся чат-оркестратор**: он генерирует,
пользователь слушает/смотрит, и если результат «не то» — открывает редактор и докручивает руками.

**Опорные сценарии конвейера:**
- **Песня → клип:** сгенерировали песню → не понравилось → в DAW разложили на дорожки,
  поправили тональности, сгенерировали новый сэмпл, наложили → добавили свой сэмпл →
  собрали клип в видеоредакторе.
- **Сценарий → фильм:** написали сценарий → раскадровка → генерация видеоряда по кускам +
  озвучка → монтаж в NLE → единый фильм 10–20 мин (перспектива до 2 ч), с качественной
  работой эффектов.

## PS-2 — Волна редакторов (✅ ДОСТАВЛЕНО 2026-09-18, браузерно верифицировано)

Четыре добивки визуального видения по обратной связи пользователя — реализованы как насыщенные
интерактивные макеты (без бэкенда, бейджи «В разработке»), функционализация — в фазах A–C ниже.
Решение пользователя по каталогизации (коллекции устраивают, не хватает каталогизации) учтено
сквозным паттерном: поиск + теги/фильтры с счётчиками + коллекции/серии + сортировка + избранное
во всех библиотеках контента.

### N1. NarrativeCore — эволюция «Документов» в модуль писателя
Модуль «Документы» получает полноценную структуру (вкладки):
- **Рукопись** — текущий 3-панельный редактор (главы, структура, ИИ-помощник).
- **Кодекс мира** — карточки лора по категориям: локации, события, предметы, фракции,
  правила мира; поиск, детальная карточка, связи между записями.
- **Персонажи** — карточки: портрет, описание, черты, **состояния по главам** (возраст,
  статус, локация — таймлайн изменений), связи (родство/союз/конфликт).
- **Альбом** — сгенерированные портреты и иллюстрации, привязанные к сущностям;
  «Сгенерировать портрет по описанию» из карточки персонажа → тайл в альбоме.
- **Канон** — проверка консистентности: список находок-предупреждений
  («глаза были зелёные в гл. 2, карие в гл. 7»), источник-глава, кнопка «Показать».

### N2. Дизайн — единый редактор (новый модуль, «Студия» в сайдбаре)
- **Режим «Растр» (Photoshop-lite):** холст, инструменты (перемещение, кисть, ластик,
  выделение, кадрирование, текст, фигуры, пипетка), панель слоёв (видимость, порядок,
  прозрачность), фильтры (яркость/контраст/насыщенность/ч-б), история отмен, зум.
  Вход из галереи изображений: «Редактировать» на тайле.
- **Режим «Дизайн» (Figma-lite):** фреймы, дерево слоёв, инспектор свойств
  (x/y/w/h, fill, radius, shadow, шрифт), выравнивание, компоненты.
- **Связка с IDE:** в превью проекта переключатель «Предпросмотр / Дизайнер»:
  выбор элемента → инспектор свойств (в фазе E — промпт-правка кода по выбранному
  элементу, курсор-стиль).
- Инструмент унифицирован: один модуль, два режима + контекст входа.

### N3. Аудио → + вкладка «Студия» (DAW, FL Studio-lite)
- **Мультитрековый таймлайн:** дорожки (Вокал/Бит/Бас/Синт/Сэмпл), клипы, playhead,
  сетка тактов, зум.
- **Библиотека сэмплов:** AI-генерация сэмпла по описанию → перетаскивание на дорожку;
  загрузка своих сэмплов; превью-плеер.
- **Секвенсор бита** (step-grid, упрощённый) для ударных.
- **Микшер:** громкость, панорама, транспонирование тональности, BPM, метроном.
- «Разложить песню на дорожки» — действие из плеера/оркестратора.
- Экспорт микса.

### N4. Видео → + вкладка «Монтаж» (NLE, Premiere/Vegas-lite)
- **Монтажный стол:** мультитрек-таймлайн (V1/V2/A1/A2/Титры), клипы из сгенерированных
  сцен, инструмент «бритва»/обрезка, магнитная привязка, переходы.
- **Эффекты:** цветокор-пресеты (визуальные LUT-плитки), скорость, титры/субтитры.
- **Медиатека:** сгенерированные сценами-кусками кадры + озвучка, drag на таймлайн.
- **Сборка фильма:** «Собрать» → прогресс-пайплайн → индикатор длительности
  (цель 10–20 мин, бейдж «перспектива до 2 ч»).
- Программный монитор + мини-микшер дорожек.

### Сквозное для PS-2
- **Оркестратор знает редакторы:** из чата/галерей/плееров — кнопки
  «Открыть в Дизайне / в Студии / в Монтажной»; welcome-чипы под сценарии.
- Сайдбар: «Дизайн» в группу Студия; синхронизация мобайл-навигации; единый стиль stone+emerald,
  тёмная тема, мобайл-фёрст, бейджи «В разработке» на местах без бэкенда.
- Файлы ≤ ~450 строк, модульные папки `src/components/studio/<module>/`.
- Верификация golden path агент-браузером (http://localhost:81) + обновление worklog.

## PS-3 — Единый поток: воркспейсы (✅ ДОСТАВЛЕНО 2026-09-18, браузерно верифицировано)

Обратная связь пользователя: всё выглядит как набор разрозненных приложений, сквозной флоу
отсутствует. «Проект» сегодня — тупо проект с кодом. Проект должен стать **воркспейсом**, в
котором живёт всё: от внутренних заметок до приложений и фильмов. Отдельные коллекции тоже
имеют место быть. Нужно **одновременно упростить и унифицировать** подход, объединить в единый
поток, но дать возможность разграничивать контексты воркспейсов.

**Реализовано:** сайдбар 15→5+Диалоги (Главная · Воркспейсы · Блокнот · Библиотека · Инструменты);
оболочка воркспейса (хедер с типом/стадией/прогрессом, крошки, единая строка вкладок по типу);
Обзор = живой пайплайн типа с артефактами по стадиям; Библиотека = глобальный браузер контента
с каталогизацией; мастер создания воркспейса (тип → название → превью пайплайна); все модули
студии встроены как вкладки воркспейса; Инструменты = Скиллы/Интеграции/Монетизация/Админ;
welcome-чипы открывают воркспейсы; промпт агента знает воркспейсы. Функционализация — Фаза A.

### N1. Модель: Workspace-first
- **Воркспейс** — центральная творческая единица (эволюция «Проекта»), с типом:
  🎬 Фильм · 📖 Книга · 🎵 Музыка · 💻 Приложение · 🌀 Универсальный.
- Всё принадлежит воркспейсу: чаты (уже есть `Thread.projectId`), заметки (уже есть
  `NoteLink`), документы, изображения, треки, сцены, файлы кода, деплои, публикации.
- Глобальный уровень: **Блокнот** (личные мысли вне воркспейсов), **Библиотека** (весь контент
  всех воркспейсов, с фильтром по воркспейсу), Скиллы, Интеграции, Админ.
- Визуальная волна работает на мок-воркспейсах; в Фазе A — `Project.type` + content-таблицы
  с `workspaceId` (см. обновление фазы A ниже).

### N2. Навигация: с ~12 пунктов к 5 глобальным + контекст воркспейса
- **Глобальный сайдбар** (упрощение):
  - ⌂ **Главная** — дашборд: последние воркспейсы, активность по всем модулям, быстрый старт;
  - 🗂 **Воркспейсы** — список/сетка воркспейсов (тип, прогресс, активность);
  - 📓 **Блокнот** — глобальные личные заметки (как сейчас);
  - 🖼 **Библиотека** — весь контент (заметки/документы/изображения/аудио/видео/файлы)
    со всех воркспейсов: каталогизация + фильтр по воркспейсу;
  - ⚙ **Инструменты** — Скиллы, Интеграции MCP, Монетизация (сводка), Админ.
- **Внутри воркспейса** — контекстная оболочка: хедер воркспейса (иконка типа, название,
  стадия) + хлебные крошки + унифицированные вкладки (состав зависит от типа, порядок един):
  **Обзор · Чат · Заметки · [Контент-вкладки типа: Документы / Медиа / Код] · Дизайн · Деплой · Доход**.
- Чат внутри воркспейса = оркестратор этого воркспейса (треды скоуплены); глобальный чат
  остаётся для «просто поговорить / спросить».

### N3. Сквозной флоу (визуально)
- **Мастер создания воркспейса**: выбор типа → название → оркестратор сразу предлагает
  план конвейера (для фильма: сценарий → раскадровка → видеоряд → озвучка → монтаж → публикация).
- **Обзор воркспейса** = живой пайплайн типа: стадийная дорожка, к стадиям цепляются
  **карточки артефактов** по мере создания (заметка → документ → картинка → трек → сцена →
  приложение → деплой). Клик по карточке открывает артефакт в нужном модуле **внутри** воркспейса.
- **Единая карточка артефакта**: одна компонента для заметки/документа/картинки/трека/сцены/
  файла — в Обзоре, в Библиотеке, в результатах чата.
- Переходы из чата: сгенерировал сцену → карточка в Обзоре + «Открыть в Монтаже» — всё
  внутри контекста воркспейса, без прыжков между «приложениями».

### N4. Судьба существующих экранов
- Проекты (код) → воркспейсы типа «Приложение»: ProjectScreen = вкладка «Код».
- Студийные модули → вкладки внутри воркспейса + глобальная Библиотека поверх тех же данных.
- Монетизация → вкладка «Доход» воркспейса + глобальная сводка в Инструментах.
- Деплой → вкладка воркспейса (Приложение/Универсальный).
- Существующие экраны **не переписываются** — встраиваются в новую оболочку.

### N5. Исполнение (визуальная волна, 4 субагента)
- **PS-3-a**: новая навигация + Главная (app-shell, sidebar, home-дашборд, мастер создания).
- **PS-3-b**: оболочка воркспейса + Обзор-пайплайны по типам + контекст чата.
- **PS-3-c**: Библиотека (единый браузер контента + карточка артефакта + каталогизация).
- **PS-3-d**: встраивание существующих модулей в контекст воркспейса + Инструменты.
- main: интеграция, браузерная верификация, обновление worklog.

### Обновление Фазы A (дополнение)
- `Project` → добавить `type` (film/book/music/app/universal); миграция существующих → app.
- Content-таблицы (Document/Chapter, WorldEntity, Character, Portrait, Image, AudioTrack,
  VideoScene…) — все с `projectId` (workspaceId), чтобы Библиотека и Обзор работали по-настоящему.

## PS-3.2 — Коррекция курса (✅ ДОСТАВЛЕНО 2026-09-18, браузерно верифицировано)

Две правки пользователя после PS-3 («уже лучше, но пара мелких правок для первоначального видения»):

### П1. Чат снова — главный инструмент и оркестратор всего
- Стор: воркспейс открывается сразу на вкладке **«Чат»** (дефолт/сброс workspaceTab);
  `WORKSPACE_TABS_BY_TYPE` — «Чат» первым для всех типов.
- Сайдбар: в «Навигации» пункт **«Чат»** — всегда первый.
- **Главная = чат-центричный экран**: настоящий `ChatArea` (embedded — прячет только свой
  мобильный хедер) занимает главную колонку; правый рельс на lg+ — приветствие, «Новый
  воркспейс», «Записать мысль», Продолжить работу, Активность, Студия в цифрах; на мобиле —
  горизонтальная лента «Продолжить работу» над чатом. Старый hero-дашборд упразднён.
- Вкладка «Чат» воркспейса — хаб оркестратора: подпись «Главный инструмент: опишите задачу —
  соберу контент и открою нужный модуль», чипы быстрого доступа к модулям этого воркспейса
  (клик → setWorkspaceTab), подсказки-поручения вместо справочных вопросов.
- prompts.ts агент-сервиса: «Чат — главный инструмент и оркестратор всего» первым пунктом.

### П2. Документы: универсальные Сущности + Аналитик (не только наратив)
- Вкладки модуля: ~~Рукопись/Кодекс/Персонажи/Альбом/Канон~~ → **Рукопись / Сущности / Альбом / Аналитик**.
- **Сущности** — единая картотека с переключателем наборов:
  - «Хроники Долгой Зимы» (narrative): персонажи/локации/события/предметы/фракции/правила —
    собраны из прежних Кодекса+Персонажей (id сохранены: портреты/альбом/таймлайны живы);
  - «Спека PocketStudio» (product): **пользователи/роли/требования/модули/интеграции** —
    документация проекта описывается тем же инструментом, что и лор книги.
  - Универсальная модель StudioEntity (kind/атрибуты/теги/связи/refs: главы ИЛИ разделы),
    видовые чипы со счётчиками, поиск/сортировка; персонажи открывают CharacterSheet
    (генерация портрета), остальные — универсальный EntitySheet («Сгенерировать описание»).
- **Аналитик** (бывш. Канон) — ревьюер текстов НЕ-кода: ищет **противоречия, недосказанности
  и расхождения** в книгах, документации и статьях. Области: «Рукопись · Хроники» /
  «Документация · Спека»; типы находок с фильтрами (Противоречие/Недосказанность/Расхождение),
  источник (гл. N / SRS-4.2 · FR-12), цитата + совет, статусы исправлено/отклонено.
- Удалены: codex-tab, characters-tab, canon-tab, canon-data, codex-entity-sheet.

## Фазы функционализации

### Фаза A — Ядро оркестратора + Документы/NarrativeCore (первая)
1. **Единый AI-интерфейс** (`src/lib/ai/`): шлюз OpenAI-compatible + Anthropic-compatible
   (chat / image / tts / asr). Провайдеры и модели настраиваются в админке; пользователи
   могут подключить свой ключ (BYOK) или выбрать платформенный прокси. z-ai удалён.
2. **Схема БД**: `Document`, `DocumentChapter` (текст, статус, версии);
   NarrativeCore: `WorldEntity` (лор: локации/события/предметы/фракции, связи),
   `Character` + `CharacterState` (состояния по главам), `Portrait`/`Illustration`
   (альбом, привязка к сущности, промпт генерации).
3. **API документов/NarrativeCore**: CRUD, дерево глав, автосохранение, счётчики слов,
   кодекс, персонажи, состояния, альбом.
4. **Редактор**: редактируемый текст глав, история версий; карточки кодекса/персонажей.
5. **Промпты**: слияние старых промптов VibeMind (анализ заметок) с режиссёрскими промптами
   видео/книги из спеков Aiflow — единый `prompts/` в agent-service.
6. Инструменты агента: `create_document`, `append_chapter`, `read_document`,
   `create_character`, `generate_portrait` (описание → портрет → альбом), `check_canon`.

### Фаза B — Изображения + Дизайн
1. `Image`, `ImageJob` в БД; API: генерация (image-generation SDK), галерея, избранное.
2. Джоб-очередь (in-process + WS-статусы в чат: «картинка готова»).
3. Инструмент агента `generate_image` (промпт из диалога → галерея).
4. Референсы (загрузка) и вариации.
5. **Дизайн-редактор (растр)**: `DesignDoc`/`Layer` в БД (JSON-операции), сохранение холста
   (dataURL → файл проекта), история операций; инструменты агента `open_in_design`,
   `apply_filter`.
6. **Дизайн-режим (фигма-лайт)** для IDE: выбор элемента в превью → маппинг на файл/строку
   (курсор-стиль, базово).

### Фаза C — Аудио (DAW) + Видео (NLE)
1. **Аудио**: `AudioTrack`; TTS-генерация (голоса студии), плеер (поток), загрузка треков.
   Инструмент `tts_render`.
2. **DAW**: `AudioProject`/`DawTrack`/`DawClip` (сэмплы, таймлайн, transpose, BPM);
   генерация сэмплов (SDK) → дорожка; экспорт микса.
3. **Видео**: сценарий → раскадровка → раскад — через LLM (JSON-структура сцен),
   превью-кадры генерацией изображений; видео-сборка (ffmpeg) — когда движок доступен.
   Инструменты `storyboard_from_script`, `render_scene`.
4. **NLE**: `VideoProject`/`TimelineClip` (сцены-куски, эффекты, титры); сборка
   короткого фильма (10–20 мин) из кусков; клип для песни.
5. Подкасты: скрипт → TTS → дорожки.

### Фаза D — Деплой + MCP (✅ ДОСТАВЛЕНО 2026-09-19 в рамках песочницы)
1. **Деплой**: Dockerfile-генератор по проекту — реализован (POST /api/workspaces/[id]/dockerfile:
   профиль Next.js/Vite/Node/Python/статика по реальным файлам → Dockerfile + .dockerignore на диск,
   карточка в «Деплое», глобальный экран Деплой доступен из сайдбара, чипы включают код-проекты).
   Сборка образа/push/SSH-деплой — вне песочницы (docker CLI отсутствует), карточки честно
   помечают это. Инструмент `deploy_project` отложен до появления Docker-движка.
2. **MCP**: реестр серверов в БД (Prisma `McpServer`, ленивый посев каталога 10 серверов на
   пользователя). **Builtin-адаптеры работают реально**: `fetch` → инструменты оркестратора
   `fetch_url` (page_reader SDK) + `web_search`; `browser` (Playwright) → `browser_read` через
   agent-browser CLI (изолированная именованная сессия `pocketstudio-agent`); `filesystem` →
   гейтинг файловых инструментов (list/read/write/delete/checkpoint) по состоянию сервера.
   Внешние stdio/sse (GitHub и др.) — конфиг сохраняется, генерируется mcp.json
   (GET /api/mcp/config), запуск серверов — полная версия (сеть песочницы закрыта, GitHub 403).
   Гейтинг в чате честный: отключённый сервер → инструмент возвращает «отключён в Интеграциях».
   Каталожный конфиг как на макете: да (ConfigPreviewCard с реальным JSON + копирование).

### Фаза E — Курсор-стиль + Скиллы + Монетизация (✅ lite 2026-09-19)

1. **Курсор-стиль правки в превью**: iframe-превью проекта, инспектор DOM по клику,
   выбор элемента → черновик в чат («Попросить агента») → агент `apply_patch`.
   Hot-reload пользовательского Next **нет** без per-user daemon; кнопка «Обновить» перезагружает static HTML.
2. **Скиллы**: импорт SKILL.md (файл/URL), создание, включение в промпт агента.
3. **Монетизация**: офферы, выплаты, simulated checkout; live — слот ключа, не Stripe-сеть.
