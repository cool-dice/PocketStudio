# Новое приложение VibeFlow

Стартовый проект, созданный в [VibeFlow](https://vibeflow.local) — chat-first
рабочем пространстве, где мысли становятся приложениями.

## Как развивать

1. Откройте диалог с агентом VibeFlow и опишите, что нужно сделать —
   агент читает и пишет файлы проекта сам.
2. Ручные правки можно вносить в редакторе кода внутри VibeFlow.

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой

Проект — стандартное приложение Next.js (App Router). Задеплойте его на
Vercel: подключите репозиторий или `vercel deploy`.
