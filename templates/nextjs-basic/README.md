# Новое приложение PocketStudio

Стартовый проект, созданный в PocketStudio — chat-first студии, где мысли
становятся приложениями.

## Как развивать

1. Откройте диалог со штурманом PocketStudio и опишите, что нужно сделать —
   агент читает и пишет файлы проекта сам.
2. Ручные правки можно вносить в редакторе кода внутри PocketStudio.

## Запуск локально

```bash
npm install
npm run dev
```
